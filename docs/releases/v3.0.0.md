# ArenaLine v3.0.0 — IEA Class Catalog Foundation

**Release status: stable**

ArenaLine v3.0.0 establishes the versioned IEA competition-class foundation and completes the private-portal cleanup required before public/external publishing work begins.

## Highlights

### Official 2026–2027 IEA class catalog

ArenaLine now ships official class reference data for Hunt Seat, Western, and Dressage.

Each catalog entry records:

- rulebook season;
- discipline;
- official class code and name;
- team level;
- ability/class family;
- individual-points eligibility;
- team-points eligibility;
- whether the class belongs in season assignments;
- active/display order;
- source rule and source revision date.

The initial season-assignable catalog contains 42 youth placement classes:

- H1–H14
- W1–W14
- D1–D14

### Season catalog configuration

Season Setup can configure:

- the applicable IEA rulebook season;
- participating disciplines;
- official season classes derived from the catalog.

Existing/manual classes remain supported. Reconciliation is conservative and does not guess from display names.

### Show Setup integration

Normal IEA classes flow through:

```text
IEAClassCatalogEntry
        ↓
SeasonClass
        ↓
ShowClass
        ↓
Entries/results
```

Official show-only classes can link directly from the catalog without entering rider season assignments.

### Official show-only warm-ups

v3.0.0 includes:

- Hunt Seat H7x/H8x and H13x/H14x
- Western W7x/W8x and W13x/W14x
- Dressage D7x/D8x and D13x/D14x

These classes:

- are regular-season show-only offerings;
- require the corresponding same-show prerequisite entry;
- do not enter rider season assignments;
- do not award individual or team points.

### Hunt Seat Varsity Open Championship (VOC)

VOC is represented as an official Hunt Seat show-only class.

ArenaLine derives eligibility from same-show H1/H2 participation/results and ranks candidates by:

1. combined H1/H2 points;
2. H1 placing.

ArenaLine does not invent unresolved judge-card tie-break data that it does not store.

VOC is regular-season only and non-scoring.

### Catalog-driven scoring policy

Scoring eligibility now resolves from effective catalog metadata instead of Hunt Seat-specific hard-coded exclusions.

Standard no-team-points classes are:

- H8 / H14
- W8 / W14
- D8 / D14

Classes with `team_points_enabled=False` cannot be points-rider/team entries. Classes with `individual_points_enabled=False` cannot retain result points.

A data migration reconciles invalid catalog-linked point-rider/team-entry state created before this policy existed.

### Legacy compatibility

Historical/unlinked records remain supported. The older H8/H14 recognition remains only as a compatibility fallback when no catalog metadata is available.

### Presentation cleanup

The legacy Calendar inline style block was removed. Calendar presentation now lives in the shared Operations stylesheet while preserving:

- Month view;
- Agenda view;
- filters;
- light/dark behavior;
- responsive/mobile switching.

### Architecture/documentation cleanup

v3.0.0 documents the boundary between generic ArenaLine platform behavior and `competition_iea`.

The release also establishes the public/external guardrail:

> Nothing becomes public merely because it exists inside ArenaLine.

Future public pages must use explicit publication controls and allow-listed data.

## Production update

Stable production installs should use:

```bash
cd /opt/iea-team-portal/app
./portalctl git-status
./portalctl update
./portalctl health
```

Do not use `portalctl upgrade` as a substitute for selecting a newer stable release. `upgrade` rebuilds the revision already checked out; `update` fetches and selects the new stable tag before rebuilding.
